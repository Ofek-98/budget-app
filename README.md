# ניהול תקציב חכם

אפליקציית ווב אישית לניהול התקציב. אין צורך בהתקנה, והנתונים לא נשלחים לשום שרת.

## הפעלה

- פותחים את `index.html` בכרום או באדג׳ (לחיצה כפולה).
- בפעם הראשונה: מסך **ייבוא**, וגוררים לשם את קובץ ה־Excel המקורי. העסקאות, הקופות, הביטוחים והמשכנתה ייטענו.
- מכאן והלאה: כל חודש גוררים את קבצי ישראכרט, אמריקן, `MAX` והבנק.

## גיבוי

- **הגדרות ← יצירת קובץ גיבוי**, ובוחרים מיקום מקומי או ענן פרטי (לא OneDrive של העבודה). האפליקציה שומרת אליו אוטומטית.
- בפתיחה מחדש ייתכן שהדפדפן יבקש לאשר שוב גישה לקובץ (כפתור בתחתית התפריט).
- בלי קובץ גיבוי הנתונים נשמרים רק בדפדפן הזה.

## מבנה

| קובץ | תפקיד |
|---|---|
| `js/parsers.js` | קריאת קבצי ישראכרט/אמריקן, MAX, בנק כללי, וה־Excel המקורי |
| `js/classifier.js` | סיווג אוטומטי: חוקים, היסטוריה, דמיון, מילות מפתח |
| `js/finance.js` | חישובי דשבורד, ממוצעים, הוצאות קבועות, בדיקות כפילויות |
| `js/mortgage.js` | לוח סילוקין, סימולציית פירעון, לפרוע או להשקיע |
| `js/ui/*` | המסכים |
